데스크탑에 설치

최종 수정일: 2026년 8월 7일

컴퓨터를 켤 때마다 카운터가 자동으로 뜨게 만들 수 있습니다. 주소창 없는 작은 창으로 열리고, 시작 메뉴와 작업 표시줄에도 등록됩니다.

설치 파일을 내려받을 필요는 없습니다. 크롬과 엣지에 들어 있는 기능이라 보안 경고 없이 두 단계면 끝납니다.

버튼이 눌리지 않으면 아래 수동 방법을 따라 주세요.

1단계 — 앱으로 설치하기

위 버튼이 동작하지 않는 브라우저라면 직접 설치할 수 있습니다.

크롬

  1. 주소창 오른쪽 끝의 설치 아이콘(모니터에 화살표가 있는 모양)을 클릭합니다.
  2. 안 보이면 오른쪽 위 ⋮ 메뉴 → 캐스트, 저장 및 공유 → 페이지를 앱으로 설치를 선택합니다.

엣지

  1. 오른쪽 위 … 메뉴 → 앱 → 이 사이트를 앱으로 설치를 선택합니다.

2단계 — 컴퓨터를 켤 때 자동으로 열기

설치만 하면 자동 실행은 아직 꺼져 있습니다. 아래에서 한 번만 켜주세요.

크롬

  1. 주소창에 chrome://apps 를 입력합니다.
  2. 목록에서 오늘만 하고 끊을게 아이콘을 우클릭합니다.
  3. 시스템 시작 시 열기를 체크합니다.

엣지

  1. 주소창에 edge://apps 를 입력합니다.
  2. 해당 앱의 세부 정보를 엽니다.
  3. 로그인할 때 시작을 켭니다.

이제 컴퓨터를 켜면 카운터가 자동으로 뜹니다. 창 크기와 위치는 마지막에 두었던 대로 기억됩니다.

지우고 싶을 때

설치한 앱이므로 윈도우의 일반적인 앱 제거 방법으로 지웁니다.

  • 자동 실행만 끄기 — 위 2단계에서 켰던 항목을 다시 끄면 됩니다. 앱은 그대로 남습니다.
  • 앱까지 지우기 — 시작 메뉴에서 오늘만 하고 끊을게를 우클릭하고 제거를 선택합니다. 또는 chrome://apps 에서 우클릭 후 Chrome에서 삭제를 고릅니다.
  • 제거해도 사이트는 그대로 남아 있으니 언제든 다시 접속할 수 있습니다.

기록은 브라우저에 남습니다. 앱을 지워도 금연·금주 일수 기록은 브라우저 저장소에 그대로 있어서, 다시 설치하면 이어서 셉니다. 기록까지 지우려면 브라우저의 사이트 데이터를 삭제하세요.

왜 설치 파일(exe)을 주지 않나

궁금해하실 수 있어 이유를 적어둡니다.

웹페이지는 보안 때문에 사용자 컴퓨터의 시작 프로그램을 직접 건드릴 수 없습니다. 그렇게 할 수 있다면 어떤 사이트든 방문만으로 자동 실행 프로그램을 심을 수 있게 되기 때문입니다.

그래서 자동 실행을 설정하는 방법은 두 가지뿐입니다.

  • 브라우저가 공식적으로 제공하는 앱 설치 기능 — 이 페이지에서 안내하는 방법입니다. 경고창이 뜨지 않고, 제거도 표준 방식으로 됩니다.
  • 실행 파일을 내려받아 실행하게 하는 방법 — 시작 프로그램을 건드리는 파일은 백신과 윈도우 SmartScreen이 경고를 띄웁니다. 코드 서명 인증서(연 수십만 원)가 있어야 경고가 사라집니다.

개인이 만든 작은 도구를 쓰겠다고 보안 경고를 무시하게 만드는 것은 좋은 습관이 아니라고 생각해서, 첫 번째 방법만 안내합니다.

휴대폰에서도 됩니다

  • 안드로이드(크롬) — 메뉴 → 홈 화면에 추가
  • 아이폰(사파리) — 공유 버튼 → 홈 화면에 추가

한 번 열어두면 인터넷이 끊겨도 열립니다. 다만 기록은 기기마다 따로 저장되므로 컴퓨터와 휴대폰의 일수는 각각 설정해야 합니다.
