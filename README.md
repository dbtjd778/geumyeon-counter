# 오늘만 하고 끊을게

금연 일수를 자동으로 세고, 목표를 넘길 때마다 축하해주는 작은 앱.

사이트: https://dbtjd778.github.io/geumyeon-counter/
문의: geumyeon.counter@gmail.com

## 쓰는 법

1. 사이트에 접속한다.
2. 첫 화면에서 **금연 시작일 / 담배 한 갑 가격 / 하루 흡연량**을 넣는다.
3. 끝. 이후로는 열 때마다 오늘이 며칠째인지 알아서 계산한다.

## 기능

- **일수 자동 계산** — 시작일과 오늘 날짜의 차이로 매번 계산하므로, 며칠 안 열어도 숫자가 틀어지지 않는다.
- **축하 효과** — 1·3·7·10·14·21·30·50·100·150·200·300·365·500·730·1000일차에 색종이가 터진다. 같은 날 여러 번 열어도 한 번만 뜬다.
- **아낀 돈 / 안 피운 담배** — 설정한 가격과 흡연량으로 계산한다.
- **평균 비교 / 기대수명 안내** — 성별과 나이를 넣으면(선택 사항) 같은 성별 평균 흡연량과 비교해주고, 그 나이에 금연했을 때 되찾는 기대수명을 안내한다.
- **금연 실패 버튼** — 확인을 한 번 거친 뒤, 화면이 잿빛으로 바뀌고 잿가루가 내려앉는다. 그 상태에서 다시 시작할 날짜를 고르면 초기화된다.
- **오프라인 지원** — 한 번 열어두면 인터넷이 없어도 열린다.

## 앱처럼 설치하기

### 컴퓨터 (Chrome / Edge)

1. 사이트 접속 → 주소창 오른쪽의 **설치** 아이콘 클릭 (또는 메뉴 → 앱 → 이 사이트를 앱으로 설치)
2. 설치하면 주소창 없는 독립 창으로 열리고, 시작 메뉴에도 등록된다.

### 컴퓨터를 켤 때 자동으로 열기

설치한 뒤:

- **Edge**: `edge://apps` → 해당 앱 → **로그인할 때 시작** 켜기
- **Chrome**: `chrome://apps` → 아이콘 우클릭 → **시스템 시작 시 열기**

### 휴대폰

- **Android (Chrome)**: 메뉴 → *홈 화면에 추가*
- **iPhone (Safari)**: 공유 → *홈 화면에 추가*

## 데이터는 어디에 저장되나

브라우저의 localStorage에만 저장된다. 서버로 아무것도 보내지 않는다.

- 저장 항목: 시작일, 담배 가격, 하루 흡연량, 성별(선택), 나이(선택), 마지막으로 축하를 본 일차
- 성별과 나이는 **입력하지 않아도 모든 기능이 동작한다.** 평균 비교와 기대수명 안내를 보여주는 용도로만 쓰인다.
- 브라우저 데이터를 지우면 설정도 함께 지워진다. 시작일만 다시 넣으면 일수는 그대로 복구된다.
- 기기마다 따로 저장되므로 폰과 컴퓨터의 기록은 동기화되지 않는다.

## 수치 출처

- **하루 평균 흡연량** (남 13.4개비 / 여 7.3개비) — [국가암정보센터, 나의 흡연상태는?](https://www.cancer.go.kr/lay1/S1T204C206/contents.do)
- **금연 연령대별 되찾는 기대수명** (25–34세 약 10년 / 35–44세 약 9년 / 45–54세 약 6년, 40세 이전 금연 시 초과 사망위험 약 90% 감소) — [Jha et al., 21st-Century Hazards of Smoking and Benefits of Cessation in the United States, NEJM 2013](https://pubmed.ncbi.nlm.nih.gov/23343063/)

이 앱은 건강 정보를 참고용으로 제공할 뿐 의학적 진단이나 치료를 대신하지 않는다.

## 직접 고치기

빌드 도구 없는 순수 정적 웹이다. `config.js`에서 축하가 터지는 날짜(`milestones`)와 문구(`milestoneMessages`)를 바꿀 수 있다.

파일을 고친 뒤에는 `sw.js` 맨 위의 `CACHE` 이름을 바꿔야 이미 접속했던 사람에게 새 버전이 내려간다.
